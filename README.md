# Cape Town Guide

My school project, a simple website about Cape Town.

I saved my work in steps so you can see how it was made:

- **step-1-start** - just the basic html, a title and a list
- **step-2-content** - added all the text, pictures and the menu (no css yet)
- **step-3-colours** - added a css file with colours, a font and the big picture at the top
- **step-4-layout** - places are now cards in a grid, more places, food and tips boxes
- **step-5-final** - the finished site: hover effects, fun fact button, back to top button and it works on phones

To open it just double click `index.html` in any of the folders.

Pictures are from Wikimedia Commons.
